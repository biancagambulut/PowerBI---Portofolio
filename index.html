📈 Population Aged 0–3 Across Europe

This project analyzes demographic changes for the population aged 0–3 across European countries using Power BI. The dashboard is fully interactive and allows trend comparison, country benchmarking, and KPI analysis.

🔍 Overview Dashboard

The main page provides a high-level view of the European population aged 0–3, with interactive KPIs, slicers and a clean UX layout.

🌍 Country Insights & Comparison

Users can select any European country and compare population trends against the European average. The design enables instant data-driven decisions.

📊 Trend Analysis

This page visualizes historical evolution and identifies growth and decline patterns for each country.

💡 Key Insights & Conclusions

The final page presents conclusions extracted from the dataset — including countries with highest growth, trends, and demographic anomalies.
